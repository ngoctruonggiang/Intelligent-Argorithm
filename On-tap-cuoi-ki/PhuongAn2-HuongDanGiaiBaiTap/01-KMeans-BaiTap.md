```

```

```
C = (Σxᵢ/n, Σyᵢ/n)
```

# 2. BÀI TẬP 1: PHÂN CỤM CƠ BẢN K=2

## 2.1. Đề bài

**Cho tập dữ liệu gồm 4 điểm:**

| Điểm | x | y |
|------|---|---|
| A | 1 | 1 |
| B | 2 | 1 |
| C | 4 | 3 |
| D | 5 | 4 |

**Yêu cầu:** Sử dụng thuật toán K-means với K=2 để phân cụm. Cho tâm ban đầu: C₁ = A(1,1), C₂ = C(4,3). Thực hiện đến khi hội tụ.

---

## 2.2. Phân tích đề

**Xác định:**
- Số điểm: m = 4
- Số cụm: K = 2
- Tâm ban đầu: C₁(1,1), C₂(4,3)

**Cần làm:**
1. Tính khoảng cách từ mỗi điểm đến các tâm
2. Gán điểm vào cụm gần nhất
3. Tính tâm mới
4. Lặp lại đến khi hội tụ

---

## 2.3. Lời giải chi tiết

### VÒNG LẶP 1

#### Bước 1: Tính khoảng cách

**Điểm A(1,1):**
```
d(A, C₁) = √[(1-1)² + (1-1)²] = √[0 + 0] = √0 = 0
d(A, C₂) = √[(4-1)² + (3-1)²] = √[9 + 4] = √13 ≈ 3.61
```
**So sánh:** 0 < 3.61 → **Gán A vào Cụm 1**

---

**Điểm B(2,1):**
```
d(B, C₁) = √[(2-1)² + (1-1)²] = √[1 + 0] = √1 = 1
d(B, C₂) = √[(4-2)² + (3-1)²] = √[4 + 4] = √8 ≈ 2.83
```
**So sánh:** 1 < 2.83 → **Gán B vào Cụm 1**

---

**Điểm C(4,3):**
```
d(C, C₁) = √[(4-1)² + (3-1)²] = √[9 + 4] = √13 ≈ 3.61
d(C, C₂) = √[(4-4)² + (3-3)²] = √[0 + 0] = √0 = 0
```
**So sánh:** 3.61 > 0 → **Gán C vào Cụm 2**

---

**Điểm D(5,4):**
```
d(D, C₁) = √[(5-1)² + (4-1)²] = √[16 + 9] = √25 = 5
d(D, C₂) = √[(5-4)² + (4-3)²] = √[1 + 1] = √2 ≈ 1.41
```
**So sánh:** 5 > 1.41 → **Gán D vào Cụm 2**

---

#### Bảng tổng hợp Vòng 1:

| Điểm | Tọa độ | d(C₁) | d(C₂) | Gán vào |
|------|--------|-------|-------|---------|
| A | (1,1) | **0** | 3.61 | Cụm 1 |
| B | (2,1) | **1** | 2.83 | Cụm 1 |
| C | (4,3) | 3.61 | **0** | Cụm 2 |
| D | (5,4) | 5 | **1.41** | Cụm 2 |

**Kết quả phân cụm Vòng 1:**
- **Cụm 1:** {A(1,1), B(2,1)}
- **Cụm 2:** {C(4,3), D(5,4)}

---

#### Bước 2: Tính tâm cụm mới

**Tâm Cụm 1:**
```
C₁_mới = ((x_A + x_B)/2, (y_A + y_B)/2)
       = ((1 + 2)/2, (1 + 1)/2)
       = (3/2, 2/2)
       = (1.5, 1)
```

**Tâm Cụm 2:**
```
C₂_mới = ((x_C + x_D)/2, (y_C + y_D)/2)
       = ((4 + 5)/2, (3 + 4)/2)
       = (9/2, 7/2)
       = (4.5, 3.5)
```

---

### VÒNG LẶP 2

**Tâm mới:** C₁(1.5, 1), C₂(4.5, 3.5)

#### Bước 1: Tính lại khoảng cách

**Điểm A(1,1):**
```
d(A, C₁) = √[(1-1.5)² + (1-1)²] = √[0.25 + 0] = √0.25 = 0.5
d(A, C₂) = √[(1-4.5)² + (1-3.5)²] = √[12.25 + 6.25] = √18.5 ≈ 4.30
```
**So sánh:** 0.5 < 4.30 → **A vẫn ở Cụm 1**

---

**Điểm B(2,1):**
```
d(B, C₁) = √[(2-1.5)² + (1-1)²] = √[0.25 + 0] = √0.25 = 0.5
d(B, C₂) = √[(2-4.5)² + (1-3.5)²] = √[6.25 + 6.25] = √12.5 ≈ 3.54
```
**So sánh:** 0.5 < 3.54 → **B vẫn ở Cụm 1**

---

**Điểm C(4,3):**
```
d(C, C₁) = √[(4-1.5)² + (3-1)²] = √[6.25 + 4] = √10.25 ≈ 3.20
d(C, C₂) = √[(4-4.5)² + (3-3.5)²] = √[0.25 + 0.25] = √0.5 ≈ 0.71
```
**So sánh:** 3.20 > 0.71 → **C vẫn ở Cụm 2**

---

**Điểm D(5,4):**
```
d(D, C₁) = √[(5-1.5)² + (4-1)²] = √[12.25 + 9] = √21.25 ≈ 4.61
d(D, C₂) = √[(5-4.5)² + (4-3.5)²] = √[0.25 + 0.25] = √0.5 ≈ 0.71
```
**So sánh:** 4.61 > 0.71 → **D vẫn ở Cụm 2**

---

#### Bảng tổng hợp Vòng 2:

| Điểm | Tọa độ | d(C₁) | d(C₂) | Gán vào |
|------|--------|-------|-------|---------|
| A | (1,1) | **0.5** | 4.30 | Cụm 1 |
| B | (2,1) | **0.5** | 3.54 | Cụm 1 |
| C | (4,3) | 3.20 | **0.71** | Cụm 2 |
| D | (5,4) | 4.61 | **0.71** | Cụm 2 |

**Kết quả:** Phân cụm **KHÔNG ĐỔI** so với Vòng 1!

---

### Kiểm tra hội tụ

**So sánh:**
- Vòng 1: Cụm 1 = {A, B}, Cụm 2 = {C, D}
- Vòng 2: Cụm 1 = {A, B}, Cụm 2 = {C, D}

**Kết luận:** Phân cụm không thay đổi → **THUẬT TOÁN HỘI TỤ**

# 3. BÀI TẬP 2: PHÂN CỤM K=3

## 3.1. Đề bài

**Cho tập dữ liệu gồm 6 điểm:**

| Điểm | x | y |
|------|---|---|
| P₁ | 1 | 1 |
| P₂ | 2 | 2 |
| P₃ | 5 | 1 |
| P₄ | 6 | 2 |
| P₅ | 3 | 5 |
| P₆ | 4 | 6 |

**Yêu cầu:** Phân cụm K=3 với tâm ban đầu: C₁ = P₁(1,1), C₂ = P₃(5,1), C₃ = P₅(3,5).

---

## 3.2. Lời giải

### VÒNG LẶP 1

#### Tính khoảng cách cho từng điểm:

**P₁(1,1):**
```
d(P₁, C₁) = √[(1-1)² + (1-1)²] = 0
d(P₁, C₂) = √[(1-5)² + (1-1)²] = √16 = 4
d(P₁, C₃) = √[(1-3)² + (1-5)²] = √[4+16] = √20 ≈ 4.47
```
→ **Gán P₁ vào Cụm 1** (min = 0)

---

**P₂(2,2):**
```
d(P₂, C₁) = √[(2-1)² + (2-1)²] = √[1+1] = √2 ≈ 1.41
d(P₂, C₂) = √[(2-5)² + (2-1)²] = √[9+1] = √10 ≈ 3.16
d(P₂, C₃) = √[(2-3)² + (2-5)²] = √[1+9] = √10 ≈ 3.16
```
→ **Gán P₂ vào Cụm 1** (min = 1.41)

---

**P₃(5,1):**
```
d(P₃, C₁) = √[(5-1)² + (1-1)²] = √16 = 4
d(P₃, C₂) = √[(5-5)² + (1-1)²] = 0
d(P₃, C₃) = √[(5-3)² + (1-5)²] = √[4+16] = √20 ≈ 4.47
```
→ **Gán P₃ vào Cụm 2** (min = 0)

---

**P₄(6,2):**
```
d(P₄, C₁) = √[(6-1)² + (2-1)²] = √[25+1] = √26 ≈ 5.10
d(P₄, C₂) = √[(6-5)² + (2-1)²] = √[1+1] = √2 ≈ 1.41
d(P₄, C₃) = √[(6-3)² + (2-5)²] = √[9+9] = √18 ≈ 4.24
```
→ **Gán P₄ vào Cụm 2** (min = 1.41)

---

**P₅(3,5):**
```
d(P₅, C₁) = √[(3-1)² + (5-1)²] = √[4+16] = √20 ≈ 4.47
d(P₅, C₂) = √[(3-5)² + (5-1)²] = √[4+16] = √20 ≈ 4.47
d(P₅, C₃) = √[(3-3)² + (5-5)²] = 0
```
→ **Gán P₅ vào Cụm 3** (min = 0)

---

**P₆(4,6):**
```
d(P₆, C₁) = √[(4-1)² + (6-1)²] = √[9+25] = √34 ≈ 5.83
d(P₆, C₂) = √[(4-5)² + (6-1)²] = √[1+25] = √26 ≈ 5.10
d(P₆, C₃) = √[(4-3)² + (6-5)²] = √[1+1] = √2 ≈ 1.41
```
→ **Gán P₆ vào Cụm 3** (min = 1.41)

---

#### Bảng tổng hợp Vòng 1:

| Điểm | d(C₁) | d(C₂) | d(C₃) | Gán vào |
|------|-------|-------|-------|---------|
| P₁(1,1) | **0** | 4 | 4.47 | Cụm 1 |
| P₂(2,2) | **1.41** | 3.16 | 3.16 | Cụm 1 |
| P₃(5,1) | 4 | **0** | 4.47 | Cụm 2 |
| P₄(6,2) | 5.10 | **1.41** | 4.24 | Cụm 2 |
| P₅(3,5) | 4.47 | 4.47 | **0** | Cụm 3 |
| P₆(4,6) | 5.83 | 5.10 | **1.41** | Cụm 3 |

**Phân cụm Vòng 1:**
- Cụm 1: {P₁, P₂}
- Cụm 2: {P₃, P₄}
- Cụm 3: {P₅, P₆}

---

#### Tính tâm mới:

**Cụm 1:** {P₁(1,1), P₂(2,2)}
```
C₁_mới = ((1+2)/2, (1+2)/2) = (1.5, 1.5)
```

**Cụm 2:** {P₃(5,1), P₄(6,2)}
```
C₂_mới = ((5+6)/2, (1+2)/2) = (5.5, 1.5)
```

**Cụm 3:** {P₅(3,5), P₆(4,6)}
```
C₃_mới = ((3+4)/2, (5+6)/2) = (3.5, 5.5)
```

---

### VÒNG LẶP 2

**Tâm mới:** C₁(1.5, 1.5), C₂(5.5, 1.5), C₃(3.5, 5.5)

# 5. BÀI TẬP 4: DỮ LIỆU 3 CHIỀU

## 5.1. Đề bài

**Cho tập dữ liệu 3D:**

| Điểm | x | y | z |
|------|---|---|---|
| A | 1 | 1 | 1 |
| B | 2 | 2 | 2 |
| C | 8 | 8 | 8 |
| D | 9 | 9 | 9 |

**Yêu cầu:** K=2, tâm ban đầu: C₁ = A, C₂ = C.

---

## 5.2. Công thức 3D

```
d(P₁, P₂) = √[(x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²]
```

---

## 5.3. Lời giải

### Tính khoảng cách

**Điểm A(1,1,1):**
```
d(A, C₁) = √[(1-1)² + (1-1)² + (1-1)²] = √0 = 0
d(A, C₂) = √[(1-8)² + (1-8)² + (1-8)²] = √[49+49+49] = √147 ≈ 12.12
```
→ **Gán A vào Cụm 1**

**Điểm B(2,2,2):**
```
d(B, C₁) = √[(2-1)² + (2-1)² + (2-1)²] = √3 ≈ 1.73
d(B, C₂) = √[(2-8)² + (2-8)² + (2-8)²] = √108 ≈ 10.39
```
→ **Gán B vào Cụm 1**

**Điểm C(8,8,8):**
```
d(C, C₁) = √[(8-1)² + (8-1)² + (8-1)²] = √147 ≈ 12.12
d(C, C₂) = 0
```
→ **Gán C vào Cụm 2**

**Điểm D(9,9,9):**
```
d(D, C₁) = √[(9-1)² + (9-1)² + (9-1)²] = √192 ≈ 13.86
d(D, C₂) = √[(9-8)² + (9-8)² + (9-8)²] = √3 ≈ 1.73
```
→ **Gán D vào Cụm 2**

### Kết quả

- **Cụm 1:** {A(1,1,1), B(2,2,2)}
- **Cụm 2:** {C(8,8,8), D(9,9,9)}

**Tâm mới:**
```
C₁ = ((1+2)/2, (1+2)/2, (1+2)/2) = (1.5, 1.5, 1.5)
C₂ = ((8+9)/2, (8+9)/2, (8+9)/2) = (8.5, 8.5, 8.5)
```

# 6. BÀI TẬP 5: XÁC ĐỊNH ĐIỀU KIỆN HỘI TỤ

## 6.1. Đề bài

**Trường hợp 1:**
- Vòng 1: Cụm 1 = {A, B}, Cụm 2 = {C, D}
- Vòng 2: Cụm 1 = {A, B}, Cụm 2 = {C, D}

**Trường hợp 2:**
- Vòng 1: Cụm 1 = {A, B, C}, Cụm 2 = {D}
- Vòng 2: Cụm 1 = {A, B}, Cụm 2 = {C, D}
- Vòng 3: Cụm 1 = {A, B}, Cụm 2 = {C, D}

---

## 6.2. Lời giải

**Trường hợp 1:**
- So sánh Vòng 1 và Vòng 2: **Phân cụm giống nhau**
- **Kết luận:** Hội tụ tại **Vòng 2**

**Trường hợp 2:**
- So sánh Vòng 1 và Vòng 2: Khác nhau (C chuyển cụm)
- So sánh Vòng 2 và Vòng 3: **Phân cụm giống nhau**
- **Kết luận:** Hội tụ tại **Vòng 3**

# 7. BÀI TẬP TỰ LUYỆN

## 7.1. Bài tập cơ bản

**Bài 1:** Cho 4 điểm: A(0,0), B(1,0), C(10,10), D(11,10). Phân cụm K=2 với tâm C₁=A, C₂=C.

**Bài 2:** Cho 5 điểm: (1,1), (2,2), (3,3), (10,10), (11,11). Phân cụm K=2.

**Bài 3:** Cho 6 điểm chia đều thành 3 cụm. Thực hiện K-means với K=3.

## 7.2. Bài tập nâng cao

**Bài 4:** Phân cụm K=2 với dữ liệu 3D: (0,0,0), (1,1,1), (5,5,5), (6,6,6).

# 8. MẸO LÀM BÀI

## 8.1. Trước khi làm

1. **Vẽ hình** để có cái nhìn trực quan
2. **Xác định** số điểm (m), số cụm (K)
3. **Ghi rõ** tâm ban đầu

## 8.2. Trong khi làm

1. **Lập bảng** khoảng cách để tránh nhầm
2. **Tính từng bước**, đừng gộp
3. **Làm tròn** đến 2 chữ số thập phân
4. **So sánh** từng điểm một

## 8.3. Giá trị căn thường gặp

| √25 | 5 |

## 8.4. Cách kiểm tra

1. **Tính lại** khoảng cách nếu có thời gian
2. **Vẽ hình** để xem phân cụm có hợp lý không
3. **Đếm** số điểm mỗi cụm (tổng = m)
