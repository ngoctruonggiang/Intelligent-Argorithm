# 1️⃣ SƠ ĐỒ NGUYÊN LÝ KNN

## 1.1. Mô hình chọn K láng giềng

```
     Dữ liệu huấn luyện:

     ●  ●     ▲  ▲
     ●        ▲
         ?
     ●  ●     ▲  ▲

     ● = Lớp A (Tròn)
     ▲ = Lớp B (Tam giác)
     ? = Điểm cần phân loại
```

## 1.2. Với K = 3

```
     ●  ●     ▲  ▲
     ●    ╭───╮  ▲
         │ ? │←── 3 điểm gần nhất: ●●▲
     ●  ●╰───╯▲  ▲

     Đếm: ● = 2, ▲ = 1
     → Kết quả: ? thuộc lớp ● (Tròn)
```

## 1.3. Với K = 5

```
     ●  ●     ▲  ▲
     ●  ╭─────────╮▲
       │    ?    │←── 5 điểm gần nhất: ●●●▲▲
     ●  ●╰─────────╯▲  ▲

     Đếm: ● = 3, ▲ = 2
     → Kết quả: ? vẫn thuộc lớp ● (Tròn)
```

# 3️⃣ CÔNG THỨC KHOẢNG CÁCH (HÌNH HỌC)

## 3.1. Khoảng cách 2D (Pytago)

```
                     B(x₂, y₂)
                    /|
                   / |
                  /  | (y₂ - y₁)
                 /   |
                /    |
    A(x₁, y₁) /______|
              (x₂ - x₁)

    d = √[(x₂-x₁)² + (y₂-y₁)²]
```

## 3.2. Ví dụ tính

```
    A(1, 1)           B(4, 5)
        ●─────────────●
        │             │
        │    d = ?    │
        │             │

    d = √[(4-1)² + (5-1)²]
      = √[3² + 4²]
      = √[9 + 16]
      = √25
      = 5
```

# 5️⃣ SƠ ĐỒ BÀI THI: K=5, 12 ĐIỂM, 3 LỚP

## 5.1. Phân bố dữ liệu trên mặt phẳng

```
    y
    8 │
    7 │           ▲(5,7)
    6 │                 ▲(6,6)
    5 │     ○(2,5)           ▲(7,5)
    4 │   ○(1,4)  ■(3,4)          ▲(6,4)
    3 │                 ■(4,3)
    2 │   ○(1,2)  ■(3,2) ■(4,2)
    1 │     ○(2,1)
    0 └──────────────────────────────── x
        1   2   3   4   5   6   7   8

    ○ = Lớp A (4 điểm)
    ■ = Lớp B (4 điểm)
    ▲ = Lớp C (4 điểm)
```

## 5.2. Phân loại Q₁(3, 3)

```
    y
    5 │     ○
    4 │   ○     ■
    3 │         ★──┐  ← Q₁(3,3)
    2 │   ○     ■  │ ■
    1 │     ○      │
    0 └────────────┴──── x
        1   2   3   4

    5 điểm gần nhất (vòng tròn quanh Q₁):

    ┌────────────────────────────┐
    │  Điểm   │ d² │    Lớp     │
    ├─────────┼────┼────────────┤
    │ (3,4)   │  1 │    ■ B     │
    │ (3,2)   │  1 │    ■ B     │
    │ (4,3)   │  1 │    ■ B     │
    │ (4,2)   │  2 │    ■ B     │
    │ (1,2)   │  5 │    ○ A     │
    └────────────────────────────┘

    Kết quả: B=4, A=1 → Q₁ thuộc lớp B
```

## 5.3. Phân loại Q₂(5, 5)

```
    y
    8 │
    7 │           ▲
    6 │        ┌──────▲
    5 │        │  ★   │      ← Q₂(5,5)
    4 │     ■  │      │▲
    3 │        │   ■  │
    2 │        └──────┘
    1 │
    0 └──────────────────── x
        3   4   5   6   7

    5 điểm gần nhất (vòng tròn quanh Q₂):

    ┌────────────────────────────┐
    │  Điểm   │ d² │    Lớp     │
    ├─────────┼────┼────────────┤
    │ (6,6)   │  2 │    ▲ C     │
    │ (6,4)   │  2 │    ▲ C     │
    │ (5,7)   │  4 │    ▲ C     │
    │ (7,5)   │  4 │    ▲ C     │
    │ (3,4)   │  5 │    ■ B     │
    └────────────────────────────┘

    Kết quả: C=4, B=1 → Q₂ thuộc lớp C
```

# 7️⃣ BẢNG TÍNH NHANH d²

```
┌────────────────────────────────────────────────────────┐
│               BẢNG BÌNH PHƯƠNG SỐ NHỎ                  │
├──────┬────┬────┬────┬────┬────┬────┬────┬────┬────────┤
│  n   │ 1  │ 2  │ 3  │ 4  │ 5  │ 6  │ 7  │ 8  │  ...   │
├──────┼────┼────┼────┼────┼────┼────┼────┼────┼────────┤
│  n²  │ 1  │ 4  │ 9  │ 16 │ 25 │ 36 │ 49 │ 64 │  ...   │
└──────┴────┴────┴────┴────┴────┴────┴────┴────┴────────┘

d² = (Δx)² + (Δy)²

VÍ DỤ: Tính d² từ (3,3) đến (1,2)
       Δx = 3-1 = 2 → 2² = 4
       Δy = 3-2 = 1 → 1² = 1
       d² = 4 + 1 = 5 ✓
```

# 8️⃣ MINH HỌA TIE-BREAKING

```
TRƯỜNG HỢP HÒA PHIẾU (K=4, 2 lớp):

    Lớp A: ●●
    Lớp B: ▲▲

    → Hòa 2-2!

GIẢI PHÁP:

    ┌─────────────────────────────────────────┐
    │ Cách 1: Chọn lớp của điểm GẦN NHẤT     │
    │         (trong 4 điểm đã chọn)          │
    │                                         │
    │ Cách 2: GIẢM K đi 1                     │
    │         K=4 → K=3, tính lại             │
    │                                         │
    │ Cách 3: Theo thứ tự xuất hiện           │
    │         (đề thi thường tránh)           │
    └─────────────────────────────────────────┘

⚠️ GHI NHỚ: Dùng K LẺ để tránh hòa khi có 2 lớp!
```
