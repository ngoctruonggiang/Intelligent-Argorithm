# 1️⃣ SƠ ĐỒ NGUYÊN LÝ KNN

## 1.1. Mô hình chọn K láng giềng

```
     Dữ liệu huấn luyện:
     
     ●  ●     ▲  ▲
     ●        ▲
         ?         
     ●  ●     ▲  ▲
     
     ● = Lớp A (Tròn)
     ▲ = Lớp B (Tam giác)
     ? = Điểm cần phân loại
```

## 1.2. Với K = 3

```
     ●  ●     ▲  ▲
     ●    ╭───╮  ▲
         │ ? │←── 3 điểm gần nhất: ●●▲
     ●  ●╰───╯▲  ▲
     
     Đếm: ● = 2, ▲ = 1
     → Kết quả: ? thuộc lớp ● (Tròn)
```

## 1.3. Với K = 5

```
     ●  ●     ▲  ▲
     ●  ╭─────────╮▲
       │    ?    │←── 5 điểm gần nhất: ●●●▲▲
     ●  ●╰─────────╯▲  ▲
     
     Đếm: ● = 3, ▲ = 2
     → Kết quả: ? vẫn thuộc lớp ● (Tròn)
```

# 3️⃣ CÔNG THỨC KHOẢNG CÁCH (HÌNH HỌC)

## 3.1. Khoảng cách 2D (Pytago)

```
                     B(x₂, y₂)
                    /|
                   / |
                  /  | (y₂ - y₁)
                 /   |
                /    |
    A(x₁, y₁) /______|
              (x₂ - x₁)
              
    d = √[(x₂-x₁)² + (y₂-y₁)²]
```

## 3.2. Ví dụ tính

```
    A(1, 1)           B(4, 5)
        ●─────────────●
        │             │
        │    d = ?    │
        │             │
        
    d = √[(4-1)² + (5-1)²]
      = √[3² + 4²]
      = √[9 + 16]
      = √25
      = 5
```
