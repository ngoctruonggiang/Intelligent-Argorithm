# 2. MINH HỌA ĐƯỜNG THẲNG

## 2.1. Đường thẳng tốt vs xấu

```
      y                              y
    8 |     ●                      8 |     ●
    6 |   ●   /                    6 |   ●
    4 | ●   /                      4 | ●  ─────────
    2 |   /                        2 |
    0 +─────────→ x                0 +─────────→ x
      0  2  4  6                     0  2  4  6

    ĐƯỜNG THẲNG TỐT                ĐƯỜNG THẲNG XẤU
    (khớp với dữ liệu)             (không khớp)
```

## 2.2. Ý nghĩa θ₀ và θ₁

```
      y
      |            /
      |           /  ← θ₁ > 0 (đi lên)
      |          /
   θ₀ ├─────────●
      |        /
      |       /
      +──────────────→ x
      0
      
θ₀ = điểm cắt trục y (khi x=0)
θ₁ = độ dốc của đường thẳng
```

# 5. BẢNG TÍNH MẪU

```
┌─────┬─────┬─────┬──────────┬───────────┬──────────────┐
│  i  │ xⁱ  │ yⁱ  │  h(xⁱ)   │ h(xⁱ)-yⁱ  │ [h(xⁱ)-yⁱ]×xⁱ│
├─────┼─────┼─────┼──────────┼───────────┼──────────────┤
│  1  │  1  │  1  │    0     │    -1     │     -1       │
│  2  │  2  │  2  │    0     │    -2     │     -4       │
│  3  │  3  │  3  │    0     │    -3     │     -9       │
├─────┼─────┼─────┼──────────┼───────────┼──────────────┤
│  Σ  │  -  │  -  │    -     │    -6     │    -14       │
└─────┴─────┴─────┴──────────┴───────────┴──────────────┘

∂J/∂θ₀ = (1/3) × (-6) = -2
∂J/∂θ₁ = (1/3) × (-14) = -4.67
```
