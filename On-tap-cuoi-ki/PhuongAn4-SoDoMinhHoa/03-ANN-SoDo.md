# 1. CẤU TRÚC MẠNG NƠ-RON

## 1.1. Mạng 3 lớp cơ bản

```
       INPUT          HIDDEN         OUTPUT
       LAYER          LAYER          LAYER
         
         ○─────────────○─────────────○
        x₁ ╲         ╱ h₁╲         ╱ ŷ
             ╲     ╱       ╲     ╱
               ╲ ╱           ╲ ╱
               ╱ ╲           ╱ ╲
             ╱     ╲       ╱     ╲
         ○─────────────○─────────────
        x₂           h₂
         
    Nhận dữ liệu    Học đặc      Đưa ra
    từ bên ngoài    trưng        kết quả
```

## 1.2. Chi tiết 1 node

```
              ┌─────────────────────────────────┐
              │            NODE                  │
              │                                  │
    x₁ ──w₁──►│   z = w₁x₁ + w₂x₂ + b          │
              │              │                  │
    x₂ ──w₂──►│              ▼                  │──► a = σ(z)
              │         a = σ(z)                │
       b ────►│                                  │
              └─────────────────────────────────┘
```

# 2. HÀM SIGMOID

## 2.1. Đồ thị Sigmoid

```
    σ(z)
    1.0 │                  ___________
        │                 /
    0.5 │────────────────/────────────
        │               /
    0.0 │______________/
        └────────────────────────────→ z
           -4  -2   0   2   4

    Đặc điểm:
    - Luôn trong (0, 1)
    - σ(0) = 0.5
    - Hình chữ S
```

## 2.2. Bảng giá trị Sigmoid

```
    ┌───────┬───────────┬───────────┐
    │   z   │   σ(z)    │   σ'(z)   │
    ├───────┼───────────┼───────────┤
    │  -2   │   0.12    │   0.11    │
    │  -1   │   0.27    │   0.20    │
    │   0   │   0.50    │   0.25    │
    │   1   │   0.73    │   0.20    │
    │   2   │   0.88    │   0.11    │
    └───────┴───────────┴───────────┘
```

# 3. FORWARD PROPAGATION

## 3.1. Sơ đồ lan truyền tiến

```
    ════════════════════════════════════════════►
                    FORWARD
    
    INPUT         HIDDEN         OUTPUT
      │              │              │
      x      →       a      →       ŷ
      │              │              │
      └──────────────┴──────────────┘
              z = Σwx + b
              a = σ(z)
```

## 3.2. Ví dụ tính từng bước

```
    x₁=0.5 ──(w₁=0.4)──┐
                        ↘
                         [Σ] ──(+0.1)──► z=0.48 ──► σ ──► a=0.618
                        ↗
    x₂=0.3 ──(w₂=0.6)──┘

    z = 0.4×0.5 + 0.6×0.3 + 0.1 = 0.48
    a = σ(0.48) = 1/(1+e⁻⁰·⁴⁸) = 0.618
```

# 4. BACKPROPAGATION

## 4.1. Sơ đồ lan truyền ngược

```
    ◄════════════════════════════════════════════
                   BACKWARD
    
    INPUT         HIDDEN         OUTPUT
      │              │              │
      x      ←       δ      ←      (ŷ-y)
      │              │              │
      └──────────────┴──────────────┘
              Cập nhật w và b
```

## 4.2. Công thức cập nhật

```
    ┌────────────────────────────────────────────┐
    │         BACKPROPAGATION                    │
    ├────────────────────────────────────────────┤
    │                                            │
    │  1. Tính sai số:                          │
    │     Error = ŷ - y                         │
    │                                            │
    │  2. Tính delta:                           │
    │     δ = Error × σ'(z)                     │
    │       = (ŷ-y) × ŷ × (1-ŷ)                │
    │                                            │
    │  3. Cập nhật:                             │
    │     w := w - α × δ × input                │
    │     b := b - α × δ                        │
    │                                            │
    └────────────────────────────────────────────┘
```

# 6. VÍ DỤ FORWARD + BACKWARD

```
┌───────────────────────────────────────────────────────────────┐
│  FORWARD                                                       │
│  ────────                                                      │
│  Input: x = 1                                                  │
│  Weight: w = 0.5, Bias: b = 0.2                               │
│                                                                │
│  z = 0.5×1 + 0.2 = 0.7                                        │
│  ŷ = σ(0.7) = 0.668                                           │
│                                                                │
├───────────────────────────────────────────────────────────────┤
│  BACKWARD (y_thực = 1, α = 0.5)                               │
│  ─────────                                                     │
│  δ = (0.668-1) × 0.668 × (1-0.668)                           │
│    = -0.332 × 0.668 × 0.332 = -0.074                         │
│                                                                │
│  w_mới = 0.5 - 0.5×(-0.074)×1 = 0.537                        │
│  b_mới = 0.2 - 0.5×(-0.074) = 0.237                          │
│                                                                │
└───────────────────────────────────────────────────────────────┘
```
