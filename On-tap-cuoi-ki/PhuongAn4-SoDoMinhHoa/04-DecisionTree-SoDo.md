# 3️⃣ ĐỒ THỊ ENTROPY

```
  Entropy(S)
       │
   1.0 ┤             ●────● (Max tại p = 0.5)
       │           /´        `\
   0.8 ┤         /´            `\
       │       /´                `\
   0.6 ┤     /´                    `\
       │   /´                        `\
   0.4 ┤  /                            \
       │ /                              \
   0.2 ┤/                                \
       │                                  \
   0.0 ┼●────────────────────────────────●─── p(+)
       0.0        0.25       0.5       0.75       1.0

     (0% Yes)                          (100% Yes)
      Thuần                              Thuần
```

**Nhận xét:**

- Entropy = 0 khi p = 0 hoặc p = 1 (thuần nhất)
- Entropy = 1 khi p = 0.5 (hỗn loạn nhất)
