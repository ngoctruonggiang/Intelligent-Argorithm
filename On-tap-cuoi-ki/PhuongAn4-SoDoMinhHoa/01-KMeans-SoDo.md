# 2. MINH HỌA TỪNG BƯỚC

## 2.1. Dữ liệu ban đầu (6 điểm)

```
      y
    6 |                         
    5 |             ●E  ●F      
    4 |         ●D              
    3 |                         
    2 |     ●B                  
    1 | ●A      ●C              
    0 +─────────────────────→ x
      0   1   2   3   4   5   6

Các điểm:
A(1,1), B(2,2), C(4,1), D(4,4), E(5,5), F(6,5)
```

## 2.2. Bước 1: Chọn tâm ban đầu (K=2)

```
      y
    6 |                         
    5 |             ●E  ●F      
    4 |         ●D              
    3 |                         
    2 |     ●B                  
    1 | ★A      ●C          ★ = Tâm cụm    
    0 +─────────────────────→ x                  
      0   1   2   3   4   5   6

Tâm: C₁ = A(1,1), C₂ = D(4,4)
```

## 2.3. Bước 2: Gán điểm vào cụm

```
      y          Cụm 1: ○      Cụm 2: △
    6 |                         
    5 |             △E  △F      
    4 |         ★₂D             
    3 |                         
    2 |     ○B                  
    1 | ★₁A     △C              
    0 +─────────────────────→ x

Cụm 1: {A, B}
Cụm 2: {C, D, E, F}
```

## 2.4. Bước 3: Tính tâm mới

```
      y
    6 |                         
    5 |             ●E  ●F      
    4 |         ●D    ★₂(4.75, 3.75)           
    3 |                         
    2 |     ●B                  
    1 | ●A  ★₁(1.5, 1.5)  ●C              
    0 +─────────────────────→ x

Tâm mới:
C₁ = ((1+2)/2, (1+2)/2) = (1.5, 1.5)
C₂ = ((4+4+5+6)/4, (1+4+5+5)/4) = (4.75, 3.75)
```

# 3. CÔNG THỨC MINH HỌA

## 3.1. Khoảng cách Euclidean

```
         B(x₂, y₂)
           ●
          /|
         / |
    d   /  | (y₂ - y₁)
       /   |
      /    |
     ●─────┘
   A(x₁, y₁)
      (x₂ - x₁)

d = √[(x₂-x₁)² + (y₂-y₁)²]
```

## 3.2. Tính tâm cụm

```
       ●P₁(x₁,y₁)
        \
         \
          ★ Centroid(x̄, ȳ)
         / \
        /   \
●P₂(x₂,y₂)   ●P₃(x₃,y₃)

x̄ = (x₁ + x₂ + x₃) / 3
ȳ = (y₁ + y₂ + y₃) / 3
```

# 6. KHI NÀO HỘI TỤ?

```
   Vòng n              Vòng n+1
                       
   Cụm 1: {A,B,C}  →   Cụm 1: {A,B,C}    ✓ GIỐNG
   Cụm 2: {D,E,F}  →   Cụm 2: {D,E,F}    ✓ GIỐNG
                       
                       → HỘI TỤ!
```

```
   Vòng n              Vòng n+1
                       
   Cụm 1: {A,B,C}  →   Cụm 1: {A,B}      ✗ KHÁC
   Cụm 2: {D,E,F}  →   Cụm 2: {C,D,E,F}  ✗ KHÁC
                       
                       → TIẾP TỤC LẶP
```
